# JVM flags required to run KFS (WAR) on JDK 21
#
# The javax.*/legacy stack in KFS (Spring 3.1, Apache OJB, CGLIB, JOTM/CAROL,
# XAPool, Quartz, JAXB) performs deep reflection and extends JDK-internal
# classes that the module system closed off in JDK 9+. The flags below open
# the required packages to the unnamed module (i.e. the webapp classpath).
#
# Usage:
#   - tomcat7-maven-plugin (mvn tomcat7:run-war): export these via MAVEN_OPTS,
#     since the plugin runs Tomcat inside the Maven JVM.
#   - standalone Tomcat: add them to CATALINA_OPTS (bin/setenv.sh).
#
# Verified with: /usr/lib/jvm/java-21-openjdk-amd64 (OpenJDK 21)

--add-opens java.base/java.lang=ALL-UNNAMED
--add-opens java.base/java.lang.reflect=ALL-UNNAMED
--add-opens java.base/java.lang.invoke=ALL-UNNAMED
--add-opens java.base/java.util=ALL-UNNAMED
--add-opens java.base/java.util.concurrent=ALL-UNNAMED
--add-opens java.base/java.text=ALL-UNNAMED
--add-opens java.base/java.math=ALL-UNNAMED
--add-opens java.base/java.net=ALL-UNNAMED
--add-opens java.base/java.io=ALL-UNNAMED
--add-opens java.base/java.security=ALL-UNNAMED
--add-opens java.base/sun.util.calendar=ALL-UNNAMED
--add-opens java.sql/java.sql=ALL-UNNAMED
--add-opens java.desktop/java.awt.font=ALL-UNNAMED
--add-exports java.rmi/sun.rmi.server=ALL-UNNAMED
--add-opens java.rmi/sun.rmi.server=ALL-UNNAMED
--add-opens java.rmi/sun.rmi.transport=ALL-UNNAMED

# Notes:
# - The java.rmi flags are required by JOTM/CAROL (JUnicastServerRef extends
#   sun.rmi.server.UnicastServerRef) used by the transactionManagerXAPool bean.
# - -Djava.locale.providers=COMPAT is NOT available on JDK 21 (the COMPAT
#   locale provider was removed in JDK 21). If date/currency formatting
#   differences vs. Java 8 are observed, they come from CLDR locale data.
